# README: Wave Energy Converters Dataset Analysis

based on :
https://archive.ics.uci.edu/dataset/494/wave+energy+converters

## Project Description
This project focuses on analyzing and modeling the performance of wave energy converters using an available dataset. The process included data preparation, exploratory data analysis (EDA), model training, and evaluation using the RMSE (Root Mean Square Error) metric.

## Analysis Steps
1. **Data Preparation**:
   - Data loading
   - Cleaning and handling missing values
   - Normalization/standardization of variables
   
2. **Exploratory Data Analysis (EDA)**:
   - Statistical analysis of variables
   - Visualization of performance trends
   - Identifying relationships between variables

3. **Model Training**:
   - Splitting data into training and test sets
   - Selecting models (e.g., regression models, tree-based models)
   - Training and hyperparameter optimization

4. **Model Evaluation**:
   - Computing RMSE for each model
   - Comparing results and selecting the best-performing model

## Requirements
- Python 3.x
- Libraries: pandas, numpy, scikit-learn, matplotlib
